    Methods — the endpoints behind every number, and what is per-chain

    Market-wide panels use the aggregate endpoints, which return the same payload for either chainId — they describe the whole market. Per-chain figures (open tasks and escrow, tasks and posters per week) are counted from /api/tasks?chainId=…, and the activity feed is the one endpoint filtered by chain. Volumes divide the API's raw 6-decimal integer by 1e6; the two chains' stablecoins are added as units. Bars in the mode and status panels use a square-root scale so the rare rows stay visible; the numbers are exact.
